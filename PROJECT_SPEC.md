# PROJECT_SPEC: cloudpedagogy-ai-capability-dashboard

## 1. Repo Name
`cloudpedagogy-ai-capability-dashboard`

## 2. One-Sentence Purpose
A visualization platform for aggregated AI capability data, showing growth and maturity across domains and time.

## 3. Problem the App Solves
Difficulty in synthesizing disparately collected assessment results at an institutional level; provides the "Heatmap" and trend analysis needed for strategic decision-making.

## 4. Primary User / Audience
Institutional leaders, department heads, and strategy teams.

## 5. Core Role in the CloudPedagogy Ecosystem
The "Insight Layer" for the capability framework; visualizes aggregated data generated by the `ai-capability-assessment` tool or institutional surveys.

## 6. Main Entities / Data Structures
- **Domain**: Standard capability domains (Awareness, Co-agency, Practice, Ethics, Governance, Renewal).
- **Band**: Maturity levels (Emerging, Developing, Embedded).
- **AggregatedRow**: Data point tracking Domain, Band, and Count for a specific time period.

## 7. Main User Workflows
1. **Data Ingestion**: Import aggregated CSV or JSON datasets conforming to the dashboard schema.
2. **Visual Analysis**: Toggle between Radar (maturity), Bar (counts), and Line (trends) charts.
3. **Filtering**: Refine views by domain, band, or context tags.

## 8. Current Features
- In-browser dataset ingestion (no backend storage).
- Radar charts for cross-domain maturity profile.
- Bar charts for distribution analysis.
- Tag-based data filtering.
- Visual theme aligned with CloudPedagogy aesthetics.

## 9. Stubbed / Partial / Incomplete Features
- Longitudinal "Trend" lines are supported in the data model but listed as potentially secondary in some prototype views.

## 10. Import / Export and Storage Model
- **Storage**: Stateless; ignores local persistence to maximize privacy and modularity.
- **Import**: CSV and JSON arrays conforming to `AggregatedRow[]`.

## 11. Relationship to Other CloudPedagogy Apps
Primary consumer of data produced by `ai-capability-assessment` and other data-collection tools in the suite.

## 12. Potential Overlap or Duplication Risks
Might overlap with generic business intelligence (BI) tools, but uniquely hardcodes CloudPedagogy domain definitions and band mappings.

## 13. Distinctive Value of This App
"Privacy-preserving by design"—it operates exclusively on anonymized, aggregated counts, ensuring compliance with institutional data policies.

## 14. Recommended Future Enhancements
(Inferred) Automated "Gap Identification" reports; benchmark comparison against synthetic institutional averages.

## 15. Anything Unclear or Inferred from Repo Contents
The exact mapping between raw 1-5 assessment scores and the "Emerging-Embedded" bands is inferred to be handled during the aggregation step before loading into the dashboard.

## 16. Capability and Governance Alignment

This tool is aligned with the CloudPedagogy Capability and Governance standard.

- Capability: The tool supports development of practical AI capability through structured interaction and workflow use.
- Governance: The tool includes lightweight, optional fields that make assumptions, risks, and decisions visible and reviewable.

This alignment ensures the tool supports both effective use of AI and responsible, accountable practice.
